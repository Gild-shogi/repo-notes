## プロジェクトの概要

架空のサンプルアプリの調査メモです。画面・API・データの責務と、次に確認する項目をまとめています。

## ディレクトリと責務

| ディレクトリ | 責務 |
|---|---|
| `src/components/` | 画面の表示とユーザー操作 |
| `src/api/` | API との通信 |
| `src/domain/` | 業務ルールと型定義 |
