# 公開用スクリーンショット

README に載せる画面例と、実データを使わず撮影するための手順。

[アプリ紹介](../../README.md) · [開発ガイド](../development.md)

## 画像とサンプル

| ファイル | 内容 |
|---|---|
| [overview.png](overview.png) | リポジトリ・ノート一覧と Markdown の閲覧画面 |
| [editor.png](editor.png) | 同じサンプルノートの編集画面 |
| [sample.md](sample.md) | 撮影に使った架空のノート本文 |

## 撮影条件

- ブラウザ単体の開発モードを使う。`src/lib/devMock.ts` のインメモリデータだけを扱い、実際の `~/.repo-notes/` には接続しない。
- 起動中のデスクトップアプリや、普段使っているノートを撮影しない。
- リポジトリ名と URL は開発モードの `mock-repo` / `github.com/mock/repo` を使う。
- ノート本文はこのディレクトリの `sample.md` を使う。顧客名・業務情報・認証情報・ローカルの個人パスを転記しない。
- 画像はアプリ領域のみ、1440 × 940 px の PNG。ブラウザのタブ・アドレスバー・OS の画面を含めない。
- UI や CSS は撮影のために改変しない。日時表示はアプリの `Asia/Tokyo` 設定に従う。

## 撮影手順

1. リポジトリ直下で `pnpm dev --host 127.0.0.1` を実行する。
2. ブラウザで `http://127.0.0.1:1420` を開き、表示されるリポジトリが `mock-repo` であることを確認する。
3. 表示領域を 1440 × 940 px に設定する。
4. `mock-repo` を選び、「＋ 新規」から「プロジェクト構成と次の作業」を作成する。
5. 編集欄の全内容を `sample.md` に置き換え、保存する。
6. プレビューに戻り、目次を折りたたみ、サンプルノートとリポジトリをピン留めする。閲覧画面を `overview.png` として保存する。
7. 「編集」を開き、保存済みの状態で `editor.png` を保存する。
8. 両方の画像を目視し、サンプル以外の情報が含まれていないことを確認する。

開発モードのノートはメモリ上にあり、ページの再読み込みで初期状態に戻る。画像はデスクトップアプリの OS ウィンドウを含まないため、ウィンドウ枠や OS 固有機能の動作例としては扱わない。
